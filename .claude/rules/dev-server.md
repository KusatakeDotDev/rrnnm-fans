# 開発サーバーとブラウザ

## 開発サーバー

出どころ: rurino-nemo-fansite#140

- **作業を終えたら、開発サーバーを自分で止める（`pnpm astro dev stop`）。** 止め忘れたサーバーが worktree ごとに溜まり、メモリを圧迫したため。自分で止まる仕組みもあるが、止まるまではメモリを使い続ける。このコマンドは、その worktree の開発サーバーを止める。Windows で `pnpm dev` を止めたあとに astro だけが残ったときも、これで止まる
- **ブラウザ（Playwright も）でページを見終わったら、ページを閉じるか別のページへ移す。** ページを開いたままだと、使われていない開発サーバーが 10 分で止まる決まりに当たらず、残り続けるため。Vite のページは、同じポートで立て直したサーバーにもつなぎ直す
- **開発サーバーが自分で止まったときに理由を確かめたいなら、`pnpm dev` の出力を読む。Astro がバックグラウンドに回したとき（`pnpm dev` がサーバーを残してすぐ終わったとき）は、立て直す前に `.astro/dev.log` を読む。** Astro は、エージェントが打ったと見分けた `pnpm dev` を、Windows 以外ではバックグラウンドに回す。そのときは理由が `.astro/dev.log` にだけ残り、バックグラウンドで立て直すとログが消えるため。Windows で `pnpm dev` を止めたあとに残った astro が止まったときは、読めないことがある

止め忘れても、使われていなければ自分で止まる。止まったら、もう一度 `pnpm dev` で立てる。止まるまでの長さは `DEV_IDLE_MINUTES`（既定 10 分）と `DEV_IDLE_MAX_MINUTES`（既定 60 分）で変えられ、それぞれ `0` にすると、その決まりでは止めない。止まる決まりと、止まった理由のログの細かいところは、`src/integrations/dev-idle.ts` の `dev-idle-shutdown` のコメントにある。

## Playwright のブラウザ

出どころ: rurino-nemo-fansite#141

- **Playwright MCP で開いたブラウザは、確かめ終えたら `browser_close` で閉じる。** 閉じないとそのセッションのあいだ残り、数百 MB を使い続ける。セッションを何日も開いたままにすることがあるので、開いたままのセッションの数だけ溜まるため。閉じても、次にページを開けば自動で起動し直す。見直す条件: Playwright MCP が、使い終えたブラウザを自分で閉じるようになったら
- **Windows で `pnpm field:contrast` を途中で止めたら、残ったスクリプトの node を、`scripts/measure-field-contrast.mjs` の先頭にある手順で止める。** node が残っているあいだはブラウザも残ってメモリを使い、開発サーバーのページを開いたままにするので、そのあいだは開発サーバーも 10 分の決まりでは止まらないため。見直す条件: Windows で pnpm のほうを止めても、スクリプトの node が残らなくなったら
